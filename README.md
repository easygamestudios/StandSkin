# StandSkin

Симулятор кейсов Standoff 2: кейсы с рулеткой, апгрейд скинов, контракты, инвентарь и live-лента дропов.
Голда виртуальная, стартовый баланс — 0 G, пополняется только промокодами.

## Запуск

Сборка не нужна, это чистые HTML, CSS и JS:

- открыть `index.html` в браузере, или
- поднять локальный сервер: `npx serve .` → http://localhost:3000

Прогресс (баланс, инвентарь) хранится в `localStorage` браузера.

## Разделы

| Раздел | Что делает |
|---|---|
| Кейсы | 11 кейсов от 0,5 до 15 000 G, открытие до 5 штук сразу, быстрый режим, шансы видны на каждом скине |
| Апгрейд | ставка из скинов и/или голды, цель и множители x1.5–x20, шанс считается по ценам |
| Контракты | 3–10 скинов меняются на один случайный |
| Инвентарь | продажа скинов, сортировка и фильтр по редкости, отправка в апгрейд |
| Вывод | заглушка, раздел в разработке |

Баланс в шапке открывает кошелёк: вкладка с промокодом и вкладка пополнения с пакетами голды.
Оплата не подключена — это витрина, голда выдаётся только по промокодам.

## Промокоды

Коды в исходниках не хранятся — в `js/promo.js` лежат только SHA-256 хэши, подсмотреть их в коде сайта нельзя.
Каждый код срабатывает один раз в одном браузере, регистр и пробелы при вводе не важны.

Действующие коды: `FQ41SU` — 2 G, `SHB8K2` — 1 G, `ARC167` — 5 G, `G9H1DF12J8A12S8TE1` — 20 000 G.

Добавить новый код:

```bash
node tools/ss.js promo НОВЫЙКОД 10
```

Скрипт выведет строку вида `'a1b2…': 10,` — её нужно вставить в объект `CODES` в `js/promo.js`.

Чтобы разрешить всем игрокам заново ввести все коды, поднимите номер версии в `CODES_KEY` (`js/core.js`),
например `standskin_codes_v3` → `standskin_codes_v4`.

## Баланс игры

Настройки в начале `js/data.js` (`CONFIG`):

| Параметр | Значение | Что делает |
|---|---|---|
| `CASE_RTP` | 0.92 | средний дроп = 92% цены кейса |
| `UPGRADE_FACTOR` | 0.95 | шанс апгрейда = ставка / цель × 0.95 (x2 → 47.5%) |
| `UPGRADE_MIN` / `UPGRADE_MAX` | 1% / 85% | границы шанса апгрейда |
| `CONTRACT_RTP` | 0.94 | контракт в среднем возвращает 94% вложенного |

Шансы выпадения не прописаны руками: для каждого кейса они подбираются автоматически (вес скина ∝ цена^−k),
чтобы матожидание совпало с `CASE_RTP`. Дорогие скины сами получают маленький шанс.
Новый скин или кейс добавляется в массивы `RAW` и `CASES_RAW` там же.

## Картинки скинов

В `textures/` лежат игровые иконки скинов (PNG 512×256, прозрачный фон) и `gold.png` — иконка голды.
Если картинки для скина нет, рисуется векторный силуэт оружия.

Заменить или добавить картинку: положить файл в `textures/`, назвав его по скину
(`AKR Treasure Hunter.png`, `akr_treasure_hunter.webp` — регистр и разделители не важны), затем:

```bash
node tools/ss.js textures
```

Скрипт привяжет файлы, обновит `textures/manifest.js` и подскажет, какие имена не распознал.

## Структура

```
index.html          разметка и подключение скриптов
css/style.css       все стили, включая мобильную версию
js/data.js          скины, кейсы, настройки баланса, расчёт шансов
js/art.js           силуэты оружия и обложки кейсов (SVG)
js/promo.js         промокоды (SHA-256) 
js/core.js          состояние, баланс, инвентарь, кошелёк, звук, модалки, роутер
js/view-*.js        экраны: кейсы, апгрейд, контракты, инвентарь, вывод
js/main.js          запуск
textures/           иконки скинов + manifest.js
tools/ss.js         промокоды и привязка картинок
```

## Важно

- Всё работает в браузере, без сервера: при желании можно отредактировать `localStorage` и накрутить себе голду.
  Для игры с друзьями это не критично, для настоящей защиты нужен бэкенд.
- Голда виртуальная: её нельзя купить, вывести или обменять на реальные деньги и настоящие скины.
- Проект фанатский и некоммерческий, с Axlebolt не связан. Права на скины Standoff 2 принадлежат Axlebolt,
  иконки взяты с витрины skins4fps.com.
